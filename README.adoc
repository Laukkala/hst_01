= Fallback hostname library for Java

// Add a short description of your project. Tell what your project does and what it's used for.

This is a simple library providing objects and methods that can be used for retrieving the name of the local host, or providing a default fallback if host name cannot be retreived.
It provides an interface and a default implementation for use in other projects, where the local host name should be retrieved.

== Features

// List your project's features
- Exposes an interface for Hostname objects
- Includes a Hostname implementation that retrieves local host name automatically, or throws an exception when failing to do so
- Includes a decorator that adds functionality to a Hostname object by providing a fallback value if host name cannot be retrieved automatically
- Includes a configuration object that can be used to pass a configured fallback hostname to a default implementation, where in case host name cannot be retrieved, the configured fallback is used instead of an exception being thrown

=== Usage
Instantiate a default Hostname object via HostnameConfig and call .asString() to retrieve the host name or fallback value:
[source,java]
----
HostnameConfig config = new HostnameConfig("defaultHostname");
FallbackHostname fallbackHostname = config.hostname();
String hostname = fallbackHostname.asString();
----

You may also implement the provided Hostname interface:
[source,java]
----
import com.teragrep.hst_01.Hostname;
public class CustomHostname implements Hostname {
    // Implement CustomHostname here
}
----
